# 星聞 · STARNEWS

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

問いは自分の AI へ。出典はいつでも目の前に。

星聞は、スマートフォンで読みやすいニュースツールです。知りたいことを自由に書き、出典付きの質問資料を用意して、ご本人の公式 AI クライアントで読み進められます。過去の記事は出典と日時を添えてアーカイブに残します。ライム色と黒を基調に、見出し・本文・資料を読み分けやすくしました。

[星聞を開く](https://mornyep.github.io/hoshi-news/) · [使い方・設定](docs/guide.ja.md) · [プライバシー・制約](docs/guide.ja.md#プライバシーと制約) · [更新情報](docs/guide.ja.md#更新)

## 利用できる機能

- 読書の要望を自由に入力。設定・保存記事・読書位置を端末の profile ごとに保存。
- 公式 AI へ手動で資料を受け渡し。確認・コピー・本人による質問の後、回答を貼り付けて読むことも可能。
- 過去の記事の原文リンク、日時、資料の範囲を確認。訳がない場合は原語と明示。
- 検証済みの AI 表示提案を適用。固定色板と最大3か所の原文強調のみで、公式警報の危険度や色は変更不可。

ウェブ画面は簡体字中国語・繁体字中国語・日本語・英語に対応しています。韓国語は文書のみです。貼付回答の自動翻訳・検証は行いません。

## 利用前に

端末の profile は認証アカウントやパスワード保護ではありません。同じブラウザを使う人は選択できます。共有端末では別のブラウザ profile を使ってください。切替・終了でページのセッションを消去し、保存済みデータは残します。貼付回答は保存しません。

サブスクリプションの自動接続は未提供です。会話の読み取りや利用枠の自動消費もありません。個人向けバックエンドは未導入で、端末間の同期や近隣災害の通知も未提供です。共有 AI の生成は停止し、過去資料の日時は保持します。

GitHub Pages は `main` のルートを公開し、ビルドは不要です。設定・開発検査・削除・権利関係は [利用ガイド](docs/guide.ja.md) にまとめています。媒体のコンテンツと商標は各権利者に帰属します。AI の要約には誤りがあり得ます。原文もご確認ください。[4.7 技術記録](docs/release-4.7.md) は過去の記録です。
