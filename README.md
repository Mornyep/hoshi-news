# 星闻 · STARNEWS

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

把问题留给自己的 AI，把来源留在眼前。

星闻是一款适合手机阅读的新闻工具。自由填写想了解的事，准备带来源的提问材料，在自己的官方 AI 客户端继续阅读。历史报道、出处与日期留在档案里，lime 与黑色的界面让标题、正文和来源各有位置。

[打开星闻](https://mornyep.github.io/hoshi-news/) · [使用与配置](docs/guide.zh-CN.md) · [隐私与限制](docs/guide.zh-CN.md#隐私与限制) · [更新说明](docs/guide.zh-CN.md#更新)

## 现在可以做什么

- 自由填写阅读要求，用本机 profile 分开保存要求、设置、收藏与阅读位置。
- 选择官方 AI 入口，检查并复制材料，自行提交，手动粘贴回答回来阅读。
- 查看历史报道、原文链接、时间和资料范围。没有可靠译文时，原语内容会明确标记。
- 应用有界的 AI 展示建议：固定色板与最多三处原文强调，不能覆盖官方警报等级或颜色。

网页界面支持简中、繁中、日语、英语。文档另提供韩语；韩语网页界面尚未提供。粘贴回答不会被网站自动翻译或核验。

## 开始阅读

打开「个人 AI」，建立或选择本机 profile，保存阅读要求。填写本次问题，勾选是否包含已保存要求。准备、检查、复制，再到所选官方 AI 官网自行提问。需要时粘贴回答，并填写模型名称。

这是手动往返，不是订阅自动接入。网站不读取聊天或代用会员额度；提供商的账号、地区与使用限制仍适用。

## 数据与部署

本机 profile 不是认证账号或密码保护。同一浏览器里的其他人可以选择它们；共用设备请使用独立浏览器 profile。切换或退出会清空本页会话，已保存的本机内容保留。回答只在当前页面显示，不写入仓库或公开档案。

GitHub Pages 从 `main` 根目录发布，无需前端构建。公共模型自动生成已停止，历史数据保留原日期。私人 Worker/Auth/数据库代码尚未部署，跨设备同步、订阅自动接入、附近灾害推送均未提供。

## 开发与来源

```sh
python3 -m unittest discover -s tests -q
node --test tests/personal-boundaries.cjs backend/tests/private.test.mjs
node --check app.js
```

后端测试需 Node 24；身份和模型网络使用模拟。DOM 检查需开发依赖 `jsdom`。静态发布与模拟测试不等于生产账户隔离验收。

媒体内容与商标归各权利人。整理和 AI 分析可能出错，不代表独立事实核查。不复制未经授权的全文或绕过付费墙。
