# 星闻 SIGNAL//BREAK · 4.3 PUBLIC BETA

**可公开体验、可个人定制的游戏式新闻网页。** 公开访问：[mornyep.github.io/hoshi-news](https://mornyep.github.io/hoshi-news/)

## 产品体验

- 移动版采用 **1.5 屏左右的轻下滑布局**：第一屏是新闻封面与速览，向下少量滑动即可访问另外的新闻目录及更多推荐。完整档案才采用长文章滚动。
- 首访可选择科技、游戏、日本生活、科学发现、世界观察；**只在当前浏览器排序，不删减公共新闻**，保留圈外信息。
- 外观可选择自动配色、酸柠、蓝、粉、紫、橙与 OVERDRIVE / 舒适阅读布局，支持系统减少动效。
- 支持本地收藏、防剧透、分享纯外观链接、本地数据清除和不存储偏好的临时模式。
- 文章包含“发生什么 / 与你有关 / 事实核验”，所有访客看到**相同的公共事件事实**，仅关联说明由本机已选择的兴趣类别决定。

## 真实的隐私边界

**当前是“各浏览器独立访客”，尚不是“已认证的云端账户”。**

- 所有公共信息保存在 `news.json` 与 `seed.js`；**里面没有用户账号、收藏、兴趣、邮件、地理位置或 API 密钥**。
- 兴趣与收藏保存在浏览器同源 `localStorage`，只在这个浏览器使用。其他设备/浏览器不会自动得到这些数据，网页也不上传这些信息。
- **同一台设备上的同一浏览器配置不能作为不同人的安全边界**，共用设备请使用浏览器独立配置、隐私浏览模式或启用临时访客模式。真正的多用户账号及跨设备同步须先接入认证和服务端逐行访问控制（RLS）。见 [多用户安全设计](docs/multiuser-architecture.md)。
- 一旦未来接入 AI，公共新闻定时摘要应集中生成后复用。若开放个人 AI，必须由用户明确授权，并在服务端隔离密钥与额度，不能在 GitHub Pages 的客户端明文保存 API Key。

## 部署

本仓库是纯静态站点，无需构建。GitHub `Settings → Pages → Deploy from a branch → main → /(root)`。

iPhone 上使用 Safari 的「添加到主屏幕」作为独立网页 App 运行。服务工作线程只缓存已列明的**公开静态资源**。

> **新闻边界**：当前只有 2026-10-08 晨报公共快照，午报、晚报、突发和 ChatGPT 定时推送尚未同步至此站。内容不是实时新闻或灾害报警，也不会凭空生成新消息。

## 文件

| 文件 | 用途 |
|---|---|
| `index.html` | 页面与设置入口，含 CSP |
| `style.css` | OVERDRIVE、舒适阅读与自适应轻下滑布局 |
| `app.js` | 本地个性化、排序、收藏、偏好隔离 |
| `news.json` | 公开新闻事实池，附原始来源 |
| `seed.js` | 同步于公共 JSON 的离线回退数据 |
| `sw.js` | 仅缓存静态公共资源的离线支持 |
| `manifest.webmanifest`、`assets/` | PWA 设置和图标 |
| `docs/multiuser-architecture.md` | 分阶段 AI 和未来账号安全架构 |
