# STARNEWS 사용 안내

[简体中文](guide.zh-CN.md) · [繁體中文](guide.zh-TW.md) · [English](guide.en.md) · [日本語](guide.ja.md) · [한국어](guide.ko.md) · [프로젝트](../README.ko.md)

## 시작하기

[STARNEWS](https://mornyep.github.io/hoshi-news/)의 Personal AI에서 로컬 profile을 만들거나 선택하고 읽기 조건을 저장하세요. 예를 들어 “일본 우주 개발을 알고 싶습니다. 공식 발표와 추측을 구분하고 날짜와 출처를 표시해 주세요.”처럼 자유롭게 적습니다. 넓은 분야 목록을 고를 필요는 없습니다.

화면은 중국어 간체·번체, 일본어, 영어를 지원합니다. 처음에는 브라우저 언어를 사용하며 설정에서 바꿀 수 있습니다. 한국어는 문서에만 제공됩니다. 신뢰할 만한 번역이 없는 기사는 원어임을 표시합니다. 붙여 넣은 답변의 언어와 정확성은 직접 확인해야 합니다.

## 사용 방법

이번 질문과 공식 AI 사이트를 선택하고 저장한 조건을 포함할지 체크합니다. 아카이브 기사를 선택하면 해당 출처가 자료에 들어갑니다. 선택한 기사가 없으면 뉴스 근거가 아직 없는 조사 요청으로 표시합니다.

자료를 준비해 출처, 날짜, 근거 범위를 확인한 뒤 복사하여 본인의 공식 AI에서 직접 제출하세요. 답변을 붙여 넣고 모델 이름을 적을 수도 있습니다. 본인이 밝힌 제공 업체, 붙여 넣은 시각, 미검증 상태를 표시합니다. 붙여 넣은 시각은 뉴스 갱신 시각이 아닙니다. 자료와 답변은 자동 전송하거나 저장하지 않습니다.

선택 사항인 표시 JSON은 `tone`과 `highlights`만 받습니다. 색상은 `lime/cyan/purple/amber`, 강조는 기존 제목·요약에 있는 2~80자 원문 최대 3곳입니다. 임의의 HTML·CSS·스크립트, 없는 문구, 공식 경보 변경은 거부합니다. 강조는 읽기 보조이며 위험도 판단이 아닙니다.

아카이브는 원래 날짜, 링크, 자료 범위를 유지합니다. RSS 발췌는 전문 확보를 뜻하지 않고 여러 링크도 독립 검증을 뜻하지 않습니다. 오프라인에서는 미리 저장한 파일만 읽습니다. 캐시된 지난 자료와 불러오기 실패를 표시하며, 최초 오프라인 방문은 보장하지 않습니다.

## 설정

일반 열람과 수동 AI에는 API 키나 백엔드가 필요 없습니다. 공식 홈페이지 링크는 구독 인증이나 자동 API 연결이 아닙니다. 업체의 계정, 지역, 이용 한도, 데이터 정책이 적용됩니다.

기존 GitHub Pages는 `main`의 루트를 게시하며 빌드가 필요 없습니다. 공용 모델 생성은 중단했고 Actions는 소스 테스트만 실행합니다. 명시적인 `--dry-run`과 `--rss-only`는 출처 수집 전용이며 일반 모델 생성 명령은 실행을 거부합니다.

개인용 백엔드는 아직 배포하지 않은 후보 코드입니다. 운영자가 사용하려면 본인의 Worker/D1과 Supabase 이메일 인증이 필요합니다. `DB`, 마이그레이션, `SUPABASE_URL`, 공개 anon key, 32바이트 AES-GCM `KEY_ENCRYPTION_SECRET`, 정확한 `ALLOWED_ORIGIN`, 이메일 콜백, 남용 방지 제한을 설정한 다음 활성화하고 배포합니다. 비밀 값은 백엔드에서 보관하고 Pages, Git, 브라우저 저장소에 넣지 않습니다. 공용 모델 이용 한도 분기는 삭제했으므로 기존 환경 설정으로 활성화할 수 없습니다.

인증 서비스가 검증한 토큰과 사용자 ID로 모든 기록을 승인해야 합니다. 암호문은 사용자와 업체에 연결됩니다. 개인 API는 `private, no-store`를 사용하고 비밀이나 대화를 로그에 남기지 않으며 업체 오류 원문을 전달하지 않습니다. CORS는 origin 기준이므로 같은 github.io의 서로 다른 프로젝트는 분리하지 못합니다. 실제 배포에는 두 계정으로 접근, 삭제, 캐시, 로그, 이메일, 모델 한도를 교차 검사해야 합니다. 모의 테스트로 대체할 수 없습니다. 정확한 경로와 명령은 [기술 부록](private-ai.md)에 보관합니다. 원격 배포 전에 운영 자원, 비용, 권한을 확인해야 합니다.

## 개인정보와 제약

로컬 profile은 저장 키만 구분하며 인증 계정이나 비밀번호 보호가 아닙니다. 같은 브라우저를 쓰는 다른 사람도 선택할 수 있습니다. 공용 기기에서는 별도의 브라우저 profile을 사용하세요. 전환하거나 나가면 새로고침하여 세션, 토큰, 준비 자료, 답변을 버립니다. 저장한 로컬 데이터는 남습니다. 현재 profile의 읽기 데이터를 지우면 조건, 설정, 저장한 기사, 읽기 위치를 삭제하고 다른 profile은 바꾸지 않습니다. 예전 방문자 기록은 자동으로 가져오지 않습니다.

수동 자료에는 이번 질문, 선택한 공개 근거, 매번 체크한 조건만 들어갑니다. 저장한 기사, 개인 기억, 대화 기록, 인증 정보는 포함하지 않습니다. 공식 AI에 제출한 뒤에는 해당 업체가 데이터를 처리합니다. 선택적인 개인 서비스는 명시적 동의 후 질문, 기사, 저장한 기억, 최근 대화를 전송합니다. 운영자가 저장 키를 복호화할 수 있으므로 종단간 암호화는 아닙니다. 앱 데이터 삭제로 인증 계정까지 삭제되지는 않습니다.

기기 간 계정, 구독 자동 연결, 개인 뉴스 자동 검색·생성, 주변 재난 알림은 아직 제공하지 않습니다. 긴급 페이지에는 실시간 지진·날씨·교통 정보가 없습니다. 기상청과 지역 정부 정보를 직접 확인하세요. 향후 경보도 AI에 의존해서는 안 되며 지연 없는 전달이나 지진 조기 경보를 약속하지 않습니다.

## 출처와 권리

언론의 글, 이미지, 상표의 권리는 각 권리자에게 있습니다. 원문 표기와 제3자 사용 조건을 유지합니다. NASA 자료에도 제3자 권리가 있을 수 있으며 CNA 등의 비상업적 이용 조건도 적용됩니다. 전문을 읽을 수 있다는 사실이 전문 재배포 허가를 뜻하지는 않습니다. 유료벽을 우회하거나 NHK 등의 전문을 허가 없이 복제하지 않습니다. 요약, 번역, AI 분석은 틀릴 수 있으며 원문 링크를 유지합니다.

## 개발

```sh
python3 -m unittest discover -s tests -q
node --test tests/personal-boundaries.cjs backend/tests/private.test.mjs
node tests/service-worker-health.cjs
node --check app.js
```

백엔드 테스트는 Node 24를 사용하며 인증과 모델 통신은 모의 환경입니다. `tests/personal-dom.cjs`에는 개발 의존성인 `jsdom`이 필요합니다. 검사를 위해 모델 구독을 소비하지 않습니다. 실제 브라우저 스크롤, 오프라인 설치, 운영 계정 분리는 따로 검증해야 합니다.
