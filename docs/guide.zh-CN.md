# 星闻使用指南

[简体中文](guide.zh-CN.md) · [繁體中文](guide.zh-TW.md) · [English](guide.en.md) · [日本語](guide.ja.md) · [한국어](guide.ko.md) · [项目介绍](../README.md)

## 入门

打开 [星闻](https://mornyep.github.io/hoshi-news/)，进入「个人 AI」。建立本机 profile 或选择已有 profile，在自由输入框保存阅读要求，例如「关注日本航天，区分官方公告和推测，标注日期与来源」。不用选择宽泛新闻分类。

网页支持简中、繁中、日语、英语，默认采用浏览器语言，也可在设置中选择。韩语目前仅用于文档。新闻、档案没有可靠译文时保留原语并标记；粘贴回答的语言和准确性需要本人检查。

## 使用

填写本次问题，选择官方 AI 入口，勾选是否包含已保存的阅读要求。打开一条历史报道可附上其来源；首页没有选中报道时，材料明确标为研究请求，不声称已经取得新闻证据。

准备材料后先检查出处、时间与资料范围，再复制到自己的官方 AI 客户端自行提交。可把回答贴回星闻，填写模型名称；页面标注本人声明的提供商、粘贴时间和未经核验状态，不把粘贴时间当作新闻更新时间。材料和回答都不自动发送或持久保存。

可选的展示 JSON 只有 `tone` 与 `highlights`：色板为 `lime/cyan/purple/amber`，最多三处2–80字符的现有标题或摘要原文。拒绝任意 HTML、CSS、脚本、杜撰文字，以及对官方警报等级或颜色的覆盖。强调是阅读提示，不是风险评级。

档案保留原日期、原文链接和资料范围。RSS 节选不等于完整文章，多来源归并也不代表独立核验。离线只能读取已经缓存的文件，页面会标明离线历史快照；加载失败会保留旧资料并显示失败，不能保证首次离线访问可用。

## 配置

普通阅读与手动 AI 不需 API Key 或后端。官方入口只打开官网，不提供订阅认证或自动调用；厂商的账号、地区、用量和数据政策适用。

静态部署使用既有 GitHub Pages：`main` → 根目录，无需构建。公共模型生成已停用，Actions 只做源码测试。`--dry-run` 与 `--rss-only` 仍是显式的纯来源采集工具，正常模型生成入口拒绝执行。

私人后端是未部署的候选代码。运营者如另行启用，需要自己的 Cloudflare Worker/D1 与 Supabase 邮箱认证：配置 `DB`、迁移、`SUPABASE_URL`、公开 anon key、32字节 AES-GCM `KEY_ENCRYPTION_SECRET`、准确 `ALLOWED_ORIGIN`、邮箱回调与限流，再修改 `ENABLED` 并部署。秘密只能在后端保管；不可放入 Pages、Git 或浏览器存储。共享模型额度分支已经删除，旧环境开关无效。

令牌必须由认证服务验证，所有记录按验证后的用户 ID 授权；密文与用户和提供商绑定。私人 API 使用 `private, no-store`，服务不记录秘密和问答，提供商错误不透传。CORS 按 origin 隔离，不能隔离同一 github.io 下的不同项目路径。真实上线仍需两个账号交叉检查读写、删除、缓存、日志、邮件和模型限额；模拟测试不足以替代。

具体接口与部署命令保留在 [私人后端技术附录](private-ai.md)。不要在未确认资源、费用和授权时执行远端部署命令。

## 隐私与限制

本机 profile 仅区分浏览器存储键，不是认证账号或密码保护。同一浏览器里的其他人可以选择它；共用设备使用独立浏览器 profile。切换或退出会重新加载并丢弃当前会话、令牌、材料和回答，本机保存内容不删除。「清空当前 profile 阅读数据」清除该 profile 的要求、设置、收藏与阅读位置，其他 profile 不变。旧访客记录保留，不自动归入新 profile。

手动材料仅包含本次问题、选中的公开资料，以及逐次勾选的阅读要求，不附带收藏、私人记忆、历史或凭据。提交官方 AI 后，数据由对应厂商处理。可选私人服务需本人明确同意后才发送问题、公开报道、保存的记忆与最近对话；服务器运营者具有解密密钥的能力，不是端到端加密。删除网站应用数据不会删除认证服务账号。

跨设备账号、订阅自动接入、网页搜索自动生成个人新闻和附近灾害推送尚未提供。紧急页没有实时地震、天气或交通源。紧急信息请直接查看气象厅与所在地政府；未来警报功能也不应依赖 AI，不能承诺零延迟或地震早期预警。

## 来源与版权

媒体内容、图片与商标归各权利人，沿用原资料中的署名与第三方使用条件。NASA 资料也须检查第三方权利；CNA 等来源的非商业限制仍适用。可合法阅读不等于允许公开全文复制。不会绕过付费墙或未经授权复刻 NHK 等媒体全文。整理、翻译与 AI 分析可能出错，原文链接始终保留。

## 开发

```sh
python3 -m unittest discover -s tests -q
node --test tests/personal-boundaries.cjs backend/tests/private.test.mjs
node tests/service-worker-health.cjs
node --check app.js
```

后端测试需 Node 24，认证与模型网络使用模拟；DOM 检查 `tests/personal-dom.cjs` 需开发依赖 `jsdom`。不会为了测试消耗模型订阅。资料、文本、颜色与本机 profile 可在测试中检查；真实浏览器滚动、离线安装与生产账号隔离须分别验收。

完整删除本地 profile：在个人 AI 面板点击“完整删除当前本地 profile”并确认，删除该 profile 的名称、关注要求、设置、收藏、阅读位置、服务地址与待登录记录。取消不删除，其他 profile 和公开缓存保留；远程账号及其数据不由此删除。未启用的私人服务如以后配置，邮箱登录链接必须在发起登录的原标签页打开。


首个自动连接为同一台 Mac 上的 ChatGPT 官方授权：个人 AI → ChatGPT → 继续使用 ChatGPT → 本机确认 → 官方登录。凭据只在本机专属目录，登录不调用模型。首次仅允许一次本人点击的有界测试；其他厂商尚未启用，一律不宣称已绑定。手机不能直连桌面本机组件，浏览器可能要求本机网络权限。手动交接为备用方式。
