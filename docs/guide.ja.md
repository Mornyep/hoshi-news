## はじめに

[星聞](https://mornyep.github.io/hoshi-news/) の「パーソナル AI」で端末の profile を作成または選択し、読書の要望を保存します。例：「日本の宇宙開発を知りたい。公式発表と推測を分け、日付と出典を示して」。大まかなカテゴリの選択は不要です。

画面は簡体字中国語・繁体字中国語・日本語・英語に対応し、初期表示はブラウザ言語に従います。設定で変更できます。韓国語は文書のみです。信頼できる訳がない記事は原語と明示して残します。貼付回答の言語や正確さは、ご本人で確認してください。

## 使い方

今回の質問と公式 AI の入口を選び、保存した要望を含めるかチェックします。アーカイブの記事を選ぶとその出典を資料に添えます。記事を選んでいない場合は、ニュースの証拠が未提供の調査依頼として準備します。

資料の出典・日時・範囲を確認し、コピーしてご本人の公式 AI で送信してください。回答を貼り付けてモデル名を記入することもできます。画面には本人申告の提供元、貼付日時、未検証の表示が付きます。貼付日時は記事の更新日時ではありません。資料や回答の自動送信・保存は行いません。

任意の表示 JSON は `tone` と `highlights` のみです。色は `lime/cyan/purple/amber`、強調は既存の見出し・要約にある2〜80文字の原文を最大3か所。任意の HTML・CSS・スクリプト、存在しない文章、公式警報の変更は拒否します。強調は読書の補助で、危険度の判定ではありません。

アーカイブは元の日付・リンク・資料の範囲を保持します。RSS 抜粋は全文取得を意味せず、複数のリンクも独立した事実確認を意味しません。オフラインでは保存済みのファイルのみ読めます。過去のキャッシュや取得失敗を表示し、初回のオフライン利用は保証しません。

## 設定

通常の閲覧と手動 AI は API キーやバックエンド不要です。公式サイトへのリンクは、サブスクリプション認証や自動 API 接続ではありません。提供元のアカウント・地域・利用枠・データ規約が適用されます。

既存の GitHub Pages は `main` のルートを公開し、ビルド不要です。共有モデル生成は停止し、Actions はソーステストのみ実行します。明示的な `--dry-run` と `--rss-only` は出典収集専用です。通常のモデル生成コマンドは実行を拒否します。

個人向けバックエンドは未導入の候補コードです。導入する運営者には、自分の Worker/D1 と Supabase メール認証が必要です。`DB`、マイグレーション、`SUPABASE_URL`、公開 anon key、32バイトの AES-GCM `KEY_ENCRYPTION_SECRET`、正確な `ALLOWED_ORIGIN`、メールのコールバックと不正利用制限を設定してから有効化・公開します。秘密はバックエンドに保管し、Pages・Git・ブラウザ保存に入れないでください。共有利用枠の分岐は削除済みで、古い環境変数では有効になりません。

認証サービスによるトークン検証後のユーザー ID で全記録を認可します。暗号文はユーザーと提供元に結び付けます。個人 API は `private, no-store` を使用し、秘密や会話をログに残さず、提供元の生のエラーを返しません。CORS は origin 単位のため、同じ github.io 内の別プロジェクトを分離しません。本番では2つのアカウントでアクセス・削除・キャッシュ・ログ・メール・利用上限を確認する必要があります。モックだけでは不十分です。[技術付録](private-ai.md) に正確なルートとコマンドを残しています。遠隔導入には運営者の資源・費用・認可の確認が必要です。

## プライバシーと制約

端末の profile は保存キーを分けるだけで、認証アカウントやパスワード保護ではありません。同じブラウザを使う人は選択できます。共有端末では別のブラウザ profile を使用してください。切替・終了でページを再読込し、セッション・トークン・資料・回答を破棄します。保存済みデータは残ります。現在の profile の読書データを消去すると、要望・設定・保存記事・読書位置を消し、他の profile は変更しません。旧ゲスト記録は自動で移しません。

手動資料は今回の質問・選択した公開資料・毎回チェックした要望だけです。保存記事、個人の記憶、会話履歴、認証情報は含みません。公式 AI に送信すると、その提供元がデータを処理します。任意の個人サービスは明示的な同意後に質問・記事・保存した記憶・直近の会話を送信します。運営者は保管キーを復号できるため、エンドツーエンド暗号化ではありません。アプリのデータ削除は認証アカウントの削除を含みません。

端末間のアカウント、サブスクリプション自動接続、個人ニュースの自動検索生成、近隣災害通知は未提供です。緊急ページにリアルタイムの地震・天気・交通データはありません。気象庁や自治体の情報を直接確認してください。将来の警報も AI に依存させず、遅延ゼロや緊急地震速報は約束しません。

## 出典と権利

媒体の文章・画像・商標は各権利者に帰属します。原資料のクレジットと第三者条件を引き継ぎます。NASA 資料でも第三者の権利を確認し、CNA などの非商用条件も尊重します。閲覧可能な全文をそのまま転載できるとは限りません。有料壁の回避や NHK などの無許可全文複製は行いません。要約・翻訳・AI 分析には誤りがあり得ます。原文リンクを残します。

## 開発

```sh
python3 -m unittest discover -s tests -q
node --test tests/personal-boundaries.cjs backend/tests/private.test.mjs
node tests/service-worker-health.cjs
node --check app.js
```

バックエンドテストは Node 24 を使用し、認証・モデル通信はモックです。`tests/personal-dom.cjs` には開発依存の `jsdom` が必要です。検査のためにサブスクリプションを消費しません。実ブラウザのスクロール、オフライン導入、本番のアカウント分離は別途確認します。
