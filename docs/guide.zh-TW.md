# 星聞使用指南

[简体中文](guide.zh-CN.md) · [繁體中文](guide.zh-TW.md) · [English](guide.en.md) · [日本語](guide.ja.md) · [한국어](guide.ko.md) · [專案介紹](../README.zh-TW.md)

## 入門

開啟 [星聞](https://mornyep.github.io/hoshi-news/)，進入「個人 AI」。建立本機 profile 或選擇已有 profile，自由保存閱讀需求，例如「關注日本航太，區分官方公告與推測，標示日期與來源」。不用選擇寬泛新聞分類。

網頁支援簡中、繁中、日語、英語，預設採用瀏覽器語言，也可在設定中選擇。韓語目前僅用於文件。新聞、檔案沒有可靠譯文時保留原語並標記；貼上的回答需由本人檢查語言與準確性。

## 使用

填寫本次問題，選擇官方 AI 入口，勾選是否包含已保存的需求。選取歷史報導可附上其來源；沒有選取報導時，資料明確標為研究請求，不聲稱已取得新聞證據。

準備後檢查出處、時間與資料範圍，再複製到自己的官方 AI 用戶端自行提交。可貼上回答並填寫模型名稱；頁面標示本人聲明的提供商、貼上時間與未查核狀態，不把貼上時間當作新聞更新時間。資料與回答不會自動傳送或持久保存。

選填的顯示 JSON 只有 `tone` 與 `highlights`：色板為 `lime/cyan/purple/amber`，最多三處2–80字元的現有標題或摘要原文。拒絕任意 HTML、CSS、腳本、杜撰文字及官方警報覆寫。強調是閱讀提示，並非風險評級。

檔案保留原日期、原文連結與資料範圍。RSS 節錄不等於完整文章，多來源連結也不代表獨立查核。離線只能讀取已快取檔案，頁面會標示離線歷史快照；載入失敗會保留舊資料並顯示失敗，不保證首次離線造訪可用。

## 設定

一般閱讀與手動 AI 無需 API Key 或後端。官方入口只開啟官網，不提供訂閱認證或自動呼叫；廠商的帳號、地區、用量與資料政策適用。

靜態部署沿用 GitHub Pages：`main` → 根目錄，無需建置。公共模型產生已停用，Actions 僅測試程式。`--dry-run` 與 `--rss-only` 仍是明確執行的來源採集工具，一般模型產生入口拒絕執行。

私人後端是尚未部署的候選程式。另行啟用需營運者自己的 Cloudflare Worker/D1 與 Supabase 信箱認證：設定 `DB`、遷移、`SUPABASE_URL`、公開 anon key、32位元組 AES-GCM `KEY_ENCRYPTION_SECRET`、精確 `ALLOWED_ORIGIN`、信箱回呼與濫用限制，再啟用和部署。秘密僅在後端保管，不可放入 Pages、Git 或瀏覽器儲存。共享模型額度分支已刪除，舊環境開關無效。

認證服務須驗證令牌，所有記錄按驗證後的使用者 ID 授權；密文綁定使用者與提供商。私人 API 使用 `private, no-store`，不記錄秘密與問答，不轉傳提供商原始錯誤。CORS 按 origin 分隔，不能隔離同一 github.io 的不同專案路徑。正式上線仍需兩帳號交叉測試讀寫、刪除、快取、日誌、郵件與模型限制，模擬不足以取代。精確介面與命令保留在 [私人後端技術附錄](private-ai.md)。執行遠端部署前須確認資源、費用與授權。

## 隱私與限制

本機 profile 僅區分瀏覽器儲存鍵，並非認證帳號或密碼保護。同一瀏覽器的其他人可以選擇它；共用裝置使用獨立瀏覽器 profile。切換或登出會重新載入並捨棄工作階段、令牌、資料與回答，已保存的本機內容不刪除。「清除目前 profile 閱讀資料」清除該 profile 的需求、設定、收藏與閱讀位置，其他 profile 不變。舊訪客記錄保留，不自動歸入新 profile。

手動資料僅含本次問題、選取的公開資料與逐次勾選的需求，不附帶收藏、私人記憶、歷史或憑證。提交官方 AI 後由該廠商處理資料。選用私人服務需本人明確同意才傳送問題、報導、保存的記憶與最近對話；伺服器營運者具有解密金鑰的能力，並非端對端加密。刪除網站應用資料不會刪除認證帳號。

跨裝置帳號、訂閱自動接入、個人新聞自動搜尋產生與附近災害推播尚未提供。緊急頁沒有即時地震、天氣或交通源，請直接查看氣象廳與所在地政府。未來警報功能也不應依賴 AI，不能承諾零延遲或地震早期預警。

## 來源與版權

媒體內容、圖片與商標歸各權利人，沿用原資料署名與第三方使用條件。NASA 資料也須檢查第三方權利，CNA 等來源非商業限制仍適用。合法可讀不等於允許公開全文複製。不繞過付費牆或未授權重製 NHK 等媒體全文。整理、翻譯與 AI 分析可能出錯，原文連結保留。

## 開發

```sh
python3 -m unittest discover -s tests -q
node --test tests/personal-boundaries.cjs backend/tests/private.test.mjs
node tests/service-worker-health.cjs
node --check app.js
```

後端測試需 Node 24，認證與模型網路使用模擬；`tests/personal-dom.cjs` 需開發依賴 `jsdom`。不為測試消耗模型訂閱。真實瀏覽器捲動、離線安裝與正式帳號隔離需分別驗收。
