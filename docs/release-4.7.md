# 4.7 实施范围与验收边界

本版本在原生静态站上增加四语界面、按语言选公共新闻、资料范围透明的档案、可部署的私人 AI 服务。保留 GitHub Pages，无站长密钥进入静态网页。任何上线结论都须另查发布记录和公开页面。

## 数据与语言

- 默认 `navigator.languages`，支持简体中文、繁体中文、日语、英语。显式选择保存在原访客偏好记录，主题、语言和阅读设置可离线使用。
- `scripts/multilingual.py` 按来源语言优先选材：每语种最多六条，兼顾公共头条与跨语言重点；可合法复用的完整正文可在同一限额内生成原创分节重述，未经语义验收不能声称完全准确。来源故障记录为不可用，不凑数。
- 机器翻译只依据公开源内容。每时段最多四次调用，不自动重试，不跟随访问人数增加。数字、日期文本、显式拉丁专名和引语有结构检查；不能证明语义完全准确，CJK 专名仍需编辑复核。
- 原语内容或翻译失败有明示标记。既有快照没有四语译文时保留原内容；不能把它们称为已经全部翻译。历史收藏也不伪造译文。
- 本次提供真实抓取的四语新闻快照及来源绑定的 NASA 四语原创档案；其他跨语言项目可能是明确的原语回退。后台密钥启用后的成功工作流才能生成新译文，本地测试不消耗模型 API。
- `--rss-only` 发布来源原语版；`--dry-run` 只取源不写数据；默认无提供商 Secret 不更改旧数据。

## 阅读档案

标题纳入同一个滚动容器，降低字号与装饰强度，深色遮罩隔离背景。提供来源链接、发表/检索时间和证据范围。RSS 简讯只支撑其明示事实，背景、时间线、数据、利益相关方资料不足会显示未提供，不能借栏目名称暗示已取得全文或完成事实核查。

NHK 不全文复制、不绕过付费墙，不从短标题捏造长文。读者可留在站内读已有整理，也始终能打开原文。NASA 的允许范围内官方供稿正文已用于四语原创长篇示例，采用来源文本指纹绑定；源文改变会停止应用旧整理。其他没有足够资料的新闻仍不伪造长篇。版权/许可与完整资料是两个独立条件。

新增 RSS 的使用条件需持续检查。中央通訊社 RSS 条款要求个人或非营利非商业用途及保留署名；如站点引入广告、收费或商业用途，应先取得许可或禁用该源。参阅 [CNA RSS 条款](https://www.cna.com.tw/about/rss.aspx)。

## 私人服务

后端代码在 `backend/`，部署步骤与隐私规则在 [private-ai.md](private-ai.md)。默认关闭；尚未配置真实 D1、Supabase 项目、服务端加密 Secret 及服务 URL 时，页面显示未配置并继续提供公共新闻。

- 身份由 Supabase 服务验证，客户端不能指定用户 ID；确认邮箱、拒绝匿名账户。
- D1 按验证身份查询偏好、本人明确保存的记忆、对话和密钥。站长公共简报不接收这些数据。
- 本人 BYOK 只经 HTTPS 提交私人服务，AES-GCM 加密；不返回密钥，不写入 localStorage。登录请求有15分钟的一次性随机状态与预期邮箱，仅用于抵御任意链接登录；验证回调后清除。登录会话仅保存在内存，回调 URL 立即去掉 token；重载需重新登录。
- 每用户每分钟 30 次 API；BYOK 最多 30 次对话/日；公共池默认关闭，显式启用后最多 5 次/用户/日、100 次/全站/日。失败的对话调用也计入额度。额度不等于供应商承诺免费。
- 对话最多保存 100 条、最长 30 天；可查看、导出、清除。应用数据删除不删除 Supabase 认证账户，认证账户需由运营者通过认证服务删除。
- 推荐使用本人保存的关注领域匹配当前候选新闻，头条优先。不是已经训练的个人推荐模型；没有自动从聊天提取记忆。
- 用户明确点击同意后才发送问题与当前报道给 AI。外部服务的保留政策由供应商决定，回答可能有误。
- 防滥用还有运营责任：Supabase 注册限速/CAPTCHA、Worker/WAF、供应商硬预算及警报。不要开放匿名无限代理。

## 验证方法

Python 数据测试；Node 后端测试使用真实内存 SQLite 的 D1 适配；浏览器测试使用真实 Chrome 和隔离夹具，没有真实登录、真实个人密钥或付费模型请求。模拟 API 成功不证明线上后端、邮箱登录或供应商账户已配置。
