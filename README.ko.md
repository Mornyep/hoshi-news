# STARNEWS · 星闻

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

질문은 내 AI에게, 출처는 바로 눈앞에.

STARNEWS는 휴대폰에서 읽기 편한 뉴스 도구입니다. 알고 싶은 내용을 자유롭게 적고, 출처가 포함된 질문 자료를 준비해 본인의 공식 AI 앱에서 이어서 읽을 수 있습니다. 지난 보도는 원문 링크와 날짜를 함께 보관합니다. 라임색과 검정을 바탕으로 제목, 본문, 자료를 구분합니다.

## 현재 제공하는 기능

- 읽기 조건을 자유롭게 입력하고 로컬 profile별로 설정, 저장한 기사, 읽기 위치를 구분합니다.
- 공식 AI 사이트로 자료를 수동 전달합니다. 확인·복사한 뒤 직접 질문하고 받은 답변을 붙여 넣어 읽을 수 있습니다.
- 지난 보도의 원문 링크, 날짜, 자료 범위를 확인합니다. 번역이 없으면 원어 자료임을 표시합니다.
- 검증된 AI 표시 제안을 적용합니다. 정해진 색상과 원문 강조 최대 3곳만 허용하며 공식 경보의 위험 등급과 색상은 바꾸지 못합니다.

웹 화면은 중국어 간체·번체, 일본어, 영어를 지원합니다. 한국어는 문서에서만 제공합니다. 붙여 넣은 답변은 자동 번역하거나 검증하지 않습니다.

## 이용 전 확인

로컬 profile은 인증 계정이나 비밀번호 보호 기능이 아닙니다. 같은 브라우저를 쓰는 다른 사람도 선택할 수 있으므로 공용 기기에서는 별도의 브라우저 profile을 사용하세요. 전환하거나 나가면 페이지 세션이 지워지고 저장된 로컬 데이터는 남습니다. 붙여 넣은 답변은 저장하지 않습니다.

구독 자동 연결은 제공하지 않습니다. 대화를 읽거나 이용 한도를 자동 사용하지 않습니다. 개인용 백엔드는 배포하지 않았고 기기 간 동기화와 주변 재난 알림도 아직 없습니다. 공용 AI 생성은 중단했으며 지난 자료의 날짜는 유지합니다.

GitHub Pages는 `main`의 루트를 게시하며 빌드가 필요 없습니다. 설정, 개발 검사, 삭제 범위, 저작권은 [전체 안내](docs/guide.ko.md)를 참고하세요. 언론 콘텐츠와 상표의 권리는 각 권리자에게 있습니다. AI 요약은 틀릴 수 있으므로 원문도 확인하세요. [4.7 기술 기록](docs/release-4.7.md)은 과거 기록입니다.
