# 星聞 · STARNEWS

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

把問題留給自己的 AI，把來源留在眼前。

星聞是一款適合手機閱讀的新聞工具。自由填寫想了解的事，準備附來源的提問資料，在自己的官方 AI 用戶端繼續閱讀。歷史報導、出處與日期留在檔案裡，lime 與黑色的介面讓標題、正文和來源各有位置。

[開啟星聞](https://mornyep.github.io/hoshi-news/) · [使用與設定](docs/guide.zh-TW.md) · [隱私與限制](docs/guide.zh-TW.md#隱私與限制) · [更新說明](docs/guide.zh-TW.md#更新)

## 現在可以做什麼

- 自由填寫閱讀需求，用本機 profile 分開保存需求、設定、收藏與閱讀位置。
- 選擇官方 AI 入口，檢查並複製資料，自行提交，手動貼上回答回來閱讀。
- 查看歷史報導、原文連結、時間與資料範圍。沒有可靠譯文時，原語內容會明確標記。
- 套用經驗證的 AI 顯示建議：固定色板與最多三處原文強調，不能覆蓋官方警報等級或顏色。

網頁介面支援簡中、繁中、日語、英語。文件另提供韓語；韓語網頁介面尚未提供。貼上的回答不會自動翻譯或查核。

## 開始閱讀

在「個人 AI」建立或選擇本機 profile，保存需求。填寫本次問題，勾選是否包含已保存需求。準備、檢查、複製，再到所選官方 AI 官網自行提問。需要時貼上回答並填寫模型名稱。

這是手動往返，並非訂閱自動接入。網站不讀取對話或代用會員額度；提供商的帳號、地區與使用限制仍適用。

## 資料與部署

本機 profile 並非認證帳號或密碼保護。共用裝置請使用獨立瀏覽器 profile。切換或登出會清除本頁工作階段，保存內容仍留在本機；回答只在目前頁面顯示，不寫入儲存庫或公開檔案。

GitHub Pages 從 `main` 根目錄發布，無需建置。公共模型自動產生已停止，歷史資料保留原日期。私人後端尚未部署，跨裝置同步、訂閱自動接入、附近災害推播均未提供。

設定、開發檢查、刪除範圍、離線行為與版本變化見 [完整指南](docs/guide.zh-TW.md)。媒體內容與商標歸各權利人。AI 整理可能出錯，原文仍須核對；不複製未授權全文或繞過付費牆。[4.7 技術記錄](docs/release-4.7.md) 保留為歷史資料。
